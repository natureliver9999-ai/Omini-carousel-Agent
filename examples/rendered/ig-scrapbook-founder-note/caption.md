# I Deleted 40 Carousels — caption pack

_Platform:_ instagram &nbsp;·&nbsp; _Goal:_ community &nbsp;·&nbsp; _Slides:_ 6

## Caption

I deleted forty carousels last month. Not because they were bad. Because they were all the same deck.

Same gradient. Same three-line hook. Same "save for later" slide. Every one of them looked like it had been extruded from the same template, because it had.

The ones that survived had one thing in common: a human had argued with them.

So now every deck has to pass one question — would a person have written this sentence out loud? If not, it gets cut.

That is the whole process. Unglamorous, effective.
